الموقع الرسمي للأستاذ عبدالوهاب الدلتوني — نسخة مشاركة الروابط

هذه النسخة جاهزة لمستودع باسم abdelwahab_eldalatony في حساب GitHub m7md-3bdo.
الرابط المفترض: https://m7md-3bdo.github.io/abdelwahab_eldalatony/

1. أنشئ مستودعًا عامًا بالاسم abdelwahab_eldalatony.
2. ارفع كل الملفات والمجلد images إلى جذر المستودع.
3. Settings > Pages > Deploy from a branch > main > /(root) > Save.
4. افتح الرابط وجرّب الصورة في https://developers.facebook.com/tools/debug/ واختر Scrape Again إذا لزم.
5. جرّب Add to Home Screen من متصفح الموبايل.

تنبيه: إذا غيرت اسم المستودع أو استخدمت دومينًا مختلفًا، عدّل روابط og:url و og:image و twitter:image و canonical في index.html أولًا.
الصورة الأصلية محفوظة بدون أي تغييرات داخل images. والصورة og-image.jpg تصميم مشاركة منفصل.
